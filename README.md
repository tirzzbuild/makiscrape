# makiscrape — Tool Directory

Direktori ringan berpalet terang untuk menjelajahi source makiscrape lewat kategori **Downloader**, **Tools**, **Stalk**, dan **Search**. Tampilan memakai font lokal yang disertakan dalam folder `assets/`.

## Jalankan

Buka `index.html` di browser atau sajikan folder ini dengan server web statis. Source lengkap dimuat dari file di dalam folder `snippets/`.

## Isi katalog

- Lima kartu menyediakan preview source, panel **LIHAT SOURCE LENGKAP**, tombol **SALIN FULL SOURCE**, dan tautan **UNDUH SOURCE**.
- **Downloader:** CapCut Template Downloader.
- **Tools:** contoh parsing halaman publik, ekstraksi heading, dan pembacaan konten dinamis.
- **Search:** contoh mengambil record dari endpoint data demo publik.
- **Stalk:** kategori ditampilkan, tetapi belum berisi source.
- Empat source umum tersimpan di `snippets/source-01.txt` sampai `snippets/source-04.txt`.
- Source CapCut Template Downloader tersimpan di `snippets/capcut-template-downloader.mjs`; komentar pemilik pada file source tetap dipertahankan, dan kartu menautkan ke saluran WhatsApp makiscrape.
- Tautan saluran WhatsApp makiscrape tersedia di navigasi dan footer.

## Catatan penggunaan

Source CapCut membaca halaman template publik dan URL video yang tersedia. Gunakan hanya untuk konten milik sendiri atau yang penggunaannya diizinkan; hormati hak kreator dan ketentuan CapCut. Katalog ini statis, tidak menjalankan scraper, dan tidak meminta data akun. Hormati kebijakan situs, izin akses, dan batas permintaan saat menggunakan source lain.
